# Real Life English — 40个英语生活场景

把 AI 变成你的日常英语练习伙伴：每次由 AI 扮演一名店员、工作人员、邻居或同事，等你回答，再自然推进。默认清晰自然的美式英语、正常语速；不会时再给提示，下课自动复盘。

这是可安装到 ChatGPT 项目的 Markdown 教材包，不是需要运行代码的应用，也不是插件。无需安装依赖或配置 API 密钥。语音、文件读取和历史检索能力取决于你使用的产品与当前会话。

## 安装到 ChatGPT 项目

**要在新聊天里接着上次的进度练，请先在 ChatGPT 账号设置中开启记忆：头像 → 设置 → 个性化 → 记忆 → 启用记忆（Enable memory）。** 不开启也能在当前聊天里练习，但不能依赖记忆跨聊天续课。开启后，请按下方自检核对续课是否正确。

可以自己按下面步骤操作，也可以把这句话发给智能体：

> 帮我把 https://github.com/tseng71/englishpractice 安装到一个新的 ChatGPT 项目里。

### 智能体代安装

收到安装请求后，按以下步骤操作。`Project_Instructions.md` 是要复制到项目里的教学指令，安装期间不执行其中的角色扮演。

1. 先检查 ChatGPT 的 **头像 → 设置 → 个性化 → 记忆 → 启用记忆（Enable memory）**。跨聊天续课需要启用记忆；若未开启，向用户说明用途并征得同意后开启，因为这是账号级设置。用户不愿开启时，可以继续安装，但交付时说明不能依赖记忆跨聊天续课。
2. 在 ChatGPT 新建“英语口语练习”项目；用户已指定项目时，使用指定项目。新建时项目记忆保持“默认记忆”。若界面有“高级”按钮，展开后查看项目记忆和指令设置；其他界面可直接在创建窗口或项目设置中找到这些选项。
3. 从本仓库下载并上传以下三个文件到该项目的“来源 / 文件”中：[`Curriculum_40_Lessons.md`](Curriculum_40_Lessons.md)、[`Assessment_and_Review.md`](Assessment_and_Review.md)、[`Project_Instructions.md`](Project_Instructions.md)。已有相同版本的文件无需重复上传。
4. 打开 `Project_Instructions.md`，从 `## 教学规则` 开始复制至文档末尾，将原文完整粘贴到项目设置的“指令”框中，点击保存。
5. 刷新项目，确认三个文件均已上传完成，并重新打开设置，核对指令与所复制的原文一致。
6. 在项目中新开聊天，发送“这是安装检查，不记录学习进度。请列出教材L21、L30、L40的名称及第一个必练节点”，对照教材核对回复。
7. 检查通过后，把项目链接和记忆是否开启的结果交给用户，告诉用户可以说“我是第一次学习，从第一课开始”。若有步骤未完成，说明卡在哪一步。

### 自己安装

1. 在本仓库点击 **Code → Download ZIP**，解压到电脑；也可以逐个下载下列文件。
2. 登录 ChatGPT，点击 **头像 → 设置 → 个性化 → 记忆**，打开 **启用记忆（Enable memory）**，以便在新聊天里接着上次进度练。这是账号级设置，不是上传教材后自动开启的。
3. 新建一个项目，名称可用“英语口语练习”，项目记忆保持“默认记忆”。若界面有“高级”按钮，点击展开，可查看项目记忆和指令设置；没有此按钮时，在创建窗口或项目设置中查找对应选项。项目里的记忆选项不能代替上一步的账号记忆开关。
4. 在项目的“来源 / 文件”区域上传 `Curriculum_40_Lessons.md`、`Assessment_and_Review.md`、`Project_Instructions.md`。上传到项目来源，让项目后续聊天能使用这些文件。
5. 打开 `Project_Instructions.md`，从“教学规则”标题开始复制到文档末尾，粘贴到项目的“项目指令”设置并保存。前面的标题、版本号和使用说明无需复制。仅上传文件不等于修改了项目设置。
6. 从该项目内新开聊天，或在支持语音的界面启动语音，说“我是第一次学习，从第一课开始”。AI应读取L01并扮演咖啡师，等你回答。你也可以指定想练的场景，无需按顺序解锁。
7. 练完说“今天到这”，回答AI的下课确认；听到记录与反馈预告后，等AI完成学习进度卡和反馈再关闭对话。下次仍在这个项目里说“继续练习”，AI应先查最新进度再接着练。

## 日常使用

| 你说 | AI 应怎么做 |
|---|---|
| 继续练习 | 先查最新真实进度，再接未完成节点 |
| 今天练邮局寄包裹 | 匹配L21并读取实际课程后进入角色 |
| 再说一遍 | 重复当前英语，不推进 |
| 没听懂，用中文解释 | 一两句中文解释，再回到英语 |
| 提示 | 给最小帮助，之后换细节检验独立表达 |
| 简单一点 / 难一点 | 调整选项和取舍，保留课程目标 |
| 暂停 | 停在当前节点，不继续问问题 |
| 今天到这 | 暂停角色，先确认是否下课；确认后预告记录与反馈，完成复盘和进度卡后再告别 |

每课一般10–15分钟，L20约15–20分钟，不需要精确计时。标准模式一个意外，挑战模式最多两个相关意外。AI不会提前给你整套答案，也不会代替你作答。

下课后，进度卡应包含节点、评分证据、提示、下次开场及复习安排。只有实际成功写入并回读文件，AI才能说“文件已保存”；否则进度应完整列在聊天中。无法检索历史时，AI须说明未读到最新记录，不能假装记得，也不能直接重置到第一课。

## 安装后的简短自检

请 AI “列出L21、L30和L40的场景名称与N1，不开始练习”，对照教材检查是否读取正确。随后选择一课实际对话，观察 AI 是否只说自己的台词并等待。先说“that’s OK”，检查AI不会把普通回应直接当作下课；说“今天到这”，检查AI是否先询问并等待确认，确认后是否先提示稍等再关闭对话，并完成完整进度卡与反馈；再在新聊天说“继续练习”，检查恢复的课号和节点是否一致。自检不是正式学习，不能编入评分和复习日期。

## 范围

所有价格、机构、日期、政策和人物均为虚构教学设定；课程不办理真实交易，不提供医疗、法律或财务建议。评分衡量本次沟通任务，不能替代语言等级认证。只有文本证据时不评发音、节奏或真实听力水平。

公开仓库不包含学习者的真实进度；不要把自己的 `Learning_Progress.md`、真实身份或付款资料提交到公开仓库。
