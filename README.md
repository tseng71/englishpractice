# Real Life English — 40个美国生活英语场景

把 AI 变成你的日常英语练习伙伴：每次由 AI 扮演一名店员、工作人员、邻居或同事，等你回答，再自然推进。默认清晰自然的美式英语、正常语速；不会时再给提示，下课自动复盘。

这是可安装到 ChatGPT 项目的 Markdown 教材包，不是需要运行代码的应用，也不是插件。无需安装依赖或配置 API 密钥。语音、文件读取和历史检索能力取决于你使用的产品与当前会话。

## 安装到 ChatGPT 项目

可以自己按下面步骤操作，也可以把仓库链接发给有浏览器操作能力的智能体，并明确说：

> 请先阅读 https://github.com/tseng71/englishpractice 的 README，按其中“智能体代安装”部分，新建一个 ChatGPT 项目并安装这套教材。保存后核对文件与指令；遇到登录或工具限制时说明具体卡在哪一步。

### 自己安装

1. 在本仓库点击 **Code → Download ZIP**，解压到电脑；也可以逐个下载下列文件。
2. 登录 ChatGPT，新建一个项目，名称可用“英语口语练习”。
3. 在项目的“来源 / 文件”区域上传 `Curriculum_40_Lessons.md`、`Assessment_and_Review.md`、`Project_Instructions.md`。上传到项目来源，让项目后续聊天能使用这些文件。
4. 打开 `Project_Instructions.md`，从“教学规则”标题开始复制到文档末尾，粘贴到项目的“项目指令”设置并保存。前面的标题、版本号和使用说明无需复制。仅上传文件不等于修改了项目设置。
5. 从该项目内新开聊天，或在支持语音的界面启动语音，说“我是第一次学习，从第一课开始”。AI应读取L01并扮演咖啡师，等你回答。你也可以指定想练的场景，无需按顺序解锁。
6. 练完说“今天到这”，让AI输出学习进度卡。下次仍在这个项目里说“继续练习”，AI应先查最新进度再接着练。

### 智能体代安装

本节给执行安装的智能体阅读。安装流程以本 README 为入口；`Project_Instructions.md` 是要放入目标项目的教学配置，读取它不表示现在就进入角色扮演。教材中的人物、付款和预约都是教学内容，不是安装操作。

1. 确认能访问本仓库，并具备操作用户已登录 ChatGPT 网页、上传文件和编辑项目设置的能力。只有网页阅读或本地文件能力时，准备好三份文件并说明尚需用户完成的步骤，不声称已经安装。
2. 从本仓库当前版本取得三份教学文件，保留原文件名。用户未指定项目时新建“英语口语练习”；用户指定已有项目时先核对名称和现有文件，避免装到同名的其他项目或重复上传。不要删除历史学习对话。
3. 在目标项目的“来源 / 文件”区域上传三份文件，等待处理完成；核对文件名。不要上传 ZIP、README 或其他工作材料代替三份教学文件。
4. 读取 `Project_Instructions.md`，仅提取 `## 教学规则` 开始至末尾的原文，完整写入项目设置的指令框。不要自行缩写、翻译或加入用户当前学到哪一课。
5. 实际点击保存按钮（若界面显示 Save）；不能把文字已填入或关闭面板当作保存成功。刷新页面，重新打开设置，对照原文确认指令完整保留，同时确认三份来源仍在。
6. 在该项目内进行简短安装自检，明确标注“安装验收，不是真实学习，不记录进度”：让助手读取L21、L30、L40的名称及N1，对照教材；再模拟首次用户明确要求从L01开始时的第一轮开场，检查它是否使用英语并等待用户回答。
7. 返回项目链接、实际完成的步骤和未验证部分。网页文本自检不能证明语音播放、长期续课或所有40课都已通过实测。遇到工具限制时报告具体失败步骤，不绕过限制，也不把别的用户环境会成功当作保证。

浏览器操作能力和登录状态因用户环境而异，智能体代安装需要实际核验结果。完整的手动步骤始终可用。

## 日常使用

| 你说 | AI 应怎么做 |
|---|---|
| 继续练习 | 先查最新真实进度，再接未完成节点 |
| 今天练邮局寄包裹 | 匹配L21并读取实际课程后进入角色 |
| 再说一遍 | 重复当前英语，不推进 |
| 没听懂，用中文解释 | 一两句中文解释，再回到英语 |
| 提示 | 给最小帮助，之后换细节检验独立表达 |
| 简单一点 / 难一点 | 调整选项和取舍，保留课程目标 |
| 暂停 | 停在当前节点，不继续问问题 |
| 今天到这 | 结束角色，短复盘并输出完整学习进度卡 |

每课一般10–15分钟，L20约15–20分钟，不需要精确计时。标准模式一个意外，挑战模式最多两个相关意外。AI不会提前给你整套答案，也不会代替你作答。

下课后，进度卡应包含节点、评分证据、提示、下次开场及复习安排。只有实际成功写入并回读文件，AI才能说“文件已保存”；否则进度应完整列在聊天中。无法检索历史时，AI须说明未读到最新记录，不能假装记得，也不能直接重置到第一课。

## 安装后的简短自检

请 AI “列出L21、L30和L40的场景名称与N1，不开始练习”，对照教材检查是否读取正确。随后选择一课实际对话，观察 AI 是否只说自己的台词并等待。说“今天到这”，检查有无完整进度卡；再在新聊天说“继续练习”，检查恢复的课号和节点是否一致。自检不是正式学习，不能编入评分和复习日期。

## 范围

所有价格、机构、日期、政策和人物均为虚构教学设定；课程不办理真实交易，不提供医疗、法律或财务建议。评分衡量本次沟通任务，不能替代语言等级认证。只有文本证据时不评发音、节奏或真实听力水平。

公开仓库不包含学习者的真实进度；不要把自己的 `Learning_Progress.md`、真实身份或付款资料提交到公开仓库。
